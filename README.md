# ניהול תיק פנסיה וגמל (Local-First)

מערכת מקומית למעקב, ניהול והערכה של תיק הפנסיה וקופות הגמל להשקעה. כל הנתונים האישיים נשארים על המחשב שלך. אין חשבון, אין שרת מרוחק ואין שליחה של יתרות או דוחות החוצה.

**עמוד המדריך החי:** https://drliron.github.io/pension-gemel-tracker/

## מה המערכת עושה

- **קליטת דוחות:** מעלים PDF, CSV או TXT, או מזינים ידנית. המערכת מוחקת ת"ז, מספרי חשבון ושמות לפני כל עיבוד, מזהה את התבנית, וממפה את המסלול לקטלוג.
- **אישור לפני שמירה:** שום דוח לא נכנס לחישובים לפני שאישרת את השדות שחולצו.
- **ציר זמן ומעברי מסלול:** מעבר בין מסלולים מזוהה מדוחות מאושרים, ומוצג על גרף הצבירה.
- **יתרה משוערכת להיום:** הערכה מהיתרה האחרונה, הפקדות חודשיות ותשואות החודשיות של המסלול. תמיד מוצג טווח, תאריך נתונים מפורש והנחות החישוב.
- **השוואה לקבוצה וסימולטור "מה אם?":** השוואת המסלול שלך לקבוצה באותה קטגוריה, ובדיקה של השפעת מעבר מסלול או שינוי בדמי ניהול על האופק שתבחר.
- **נתוני שוק:** ייבוא ידני של CSV כגיבוי. שליפה אוטומטית ממקור רשמי מוגדרת אבל כבויה עד שתאשר את תנאי השימוש.

## ארכיטקטורה

הנתונים זורמים דרך צנרת דטרמיניסטית של מודולים. כל מודול מקבל ומחזיר נתונים מובנים, ואין בה קריאות ל-LLM.

```
קובץ דוח
  │
  ▼
[1] קליטה וחילוץ ──► מחיקת מזהים (redact.py) ──► בחירת תבנית ──► שדות + ביטחון
  │                                                              │
  ▼                                                              ▼
[2] מיפוי מסלול ──► track_key מהקטלוג (התאמה מדויקת בלבד, דו-משמעות נדחית)
  │
  ▼
[3] טיוטה ──► אישור משתמש ──► שמירה למסד (SQLite, מקומי)
  │
  ├──► [4] ציר זמן ומעברי מסלול (רק מדוחות מאושרים)
  ├──► [5] יתרה משוערכת (return_compounding_v1, עם טווח)
  └──► [6] חשיפות, השוואה, סימולטור, ציון בריאות (היוריסטיקה שקופה)
```

| שכבה | קבצים | תפקיד |
|---|---|---|
| Worker (Python) | `worker/app/` | צנרת, מסד, שרת HTTP על 127.0.0.1 בלבד |
| חוזה נתונים | `worker/schema/pension_portfolio.schema.json` | JSON Schema, נבדק מול המסד בטסטים |
| Frontend (React, TypeScript, Tailwind, Recharts) | `web/` | ממשק בעברית, RTL |
| נתוני דמה | `data/fixtures/` | קופות בדויות ותרחיש עם מעבר מסלול |
| עמוד מדריך | `docs/index.html` | עמוד סטטי ל-GitHub Pages |

## דרישות מוקדמות

- Python 3.11 ומעלה
- Node.js 20 ומעלה (רק לממשק)
- Git

## התקנה מהירה

```bash
git clone https://github.com/drliron/pension-gemel-tracker.git
cd pension-gemel-tracker

# 1. Worker
cd worker
pip install -r requirements.txt
python3 -m pytest -q tests              # צריך לעבור 40 טסטים
python3 -m app.server --seed            # נתוני דמה, http://127.0.0.1:8765

# 2. Frontend (בטרמינל נפרד)
cd ../web
npm install
npm run dev                             # http://127.0.0.1:5173
```

לבנייה לפרודקשן: `npm run build`. השרת המקומי מגיש את `web/dist` מהנתיב `/`.

## פרטיות

- **מחיקה לפני עיבוד:** רצה על כל דוח לפני בחירת תבנית, מיפוי או שמירה. נמחקים ת"ז (עם תווית ובלי), מספרי חשבון ופוליסה, ושורות "שם: ...".
- **לא נשמר טקסט גולמי:** נשמר רק hash של קובץ המקור. טיוטה לא נשמרת בלי אישור.
- **רשת:** השרת קושר ל-127.0.0.1 בלבד. בקשות יוצאות מכילות רק קודי קופה ומסלול ציבוריים, ובטסט נבדק שאף שדה אישי לא נשלח.
- **שליפה כבויה כברירת מחדל:** מקור רשמי נשלף רק אחרי URL מוגדר, אישור תנאי שימוש והפעלה מפורשת.
- **Git:** `.gitignore` מחריג מסדי נתונים, מטמון, PDF, קבצי `.env` ותיקיות דוחות. בריפו נשארים רק נתוני דמה אנונימיים.
